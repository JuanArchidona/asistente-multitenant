# Enunciado — Módulo 3.3: Evaluación de agentes

> Transcripción del enunciado publicado en el campus virtual.

Habiendo visto todo lo que implica crear un agente robusto, ahora nos toca
pensar en cómo vamos a validar que hace lo que debe.

Los que estéis empleando el proyecto base de resumen de reuniones tenéis una
buena guía para inspiraros en los ejemplos de DeepEval.

Deberemos crear unos ejemplos que contengan tarea y respuesta esperada, métricas
a emplear en cada caso dependiendo de si usamos RAG, si nos preocupa el filtrado
de información privada, etc...

Si podéis además tener un primer intento y valoración del resultado de vuestro
MVP o piloto, mejor que mejor, ya que sabremos cómo de lejos estamos de tener
algo que funcione en los términos que necesitamos.

## Entrega

- **Nivel mínimo:** Banco de pruebas de vuestra aplicación
- **Nivel medio:** Selección de métricas objetivo
- **Nivel pro:** Ejecución de las pruebas y valoración de vuestro MVP
- **Nivel Peter Steinberger:** Generadas pruebas sintéticas expandiendo vuestras
  pruebas iniciales
