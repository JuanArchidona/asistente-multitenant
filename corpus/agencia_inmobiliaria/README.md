# Corpus del inquilino `agencia_inmobiliaria`

Todo lo que hay en esta carpeta es **sintético**. Domara Inmobiliaria es una
empresa ficticia creada para este proyecto: no existe, y ninguno de sus
procedimientos, tarifas o acuerdos corresponde a ninguna agencia real.

Los precios y superficies que aparecen se calibraron sobre rangos de mercado
reales de Zaragoza consultados en septiembre de 2026, pero ningún inmueble,
cliente ni operación es real.

Este fichero no se indexa: la ingesta solo recorre los subdirectorios de fuente.
